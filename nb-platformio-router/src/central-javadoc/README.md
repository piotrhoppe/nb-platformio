# PlatformIO Updates (`nb-platformio-router`)

This module contains no Java API and ships no documentation. Its only role is
to register the **PlatformIO Updates** update center in Apache NetBeans using
the declarative layer `org/netbeans/module/platformio/updates/layer.xml`.

For up-to-date documentation, releases, and the update site itself, see the
project repository: <https://github.com/piotrhoppe/nb-platformio>

This JAR is a placeholder required by the Maven Central publishing rules for
artifacts without Javadoc.
