# NB PlatformIO Kit (`nb-platformio-kit`)

This module contains no Java sources. It is a sourceless aggregator that
depends on the **PlatformIO Project** and **Serial Monitor** modules, so
installing it in Apache NetBeans enforces the installation of both.

For up-to-date documentation and releases, see the project repository:
<https://github.com/piotrhoppe/nb-platformio>

This JAR is a placeholder required by the Maven Central publishing rules for
artifacts without sources.
